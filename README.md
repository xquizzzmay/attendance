# Посещаемость — для старост групп

Старосты отмечают на каждой паре, кто пришёл (+), а кто нет (−). В пятницу в 15:10 по Ташкенту неделя закрывается,
и в «Итоге недели» видно, кто сколько пар пропустил и в какие дни.

| Часть | Где лежит | Где работает | Цена |
| --- | --- | --- | --- |
| Сайт | `docs/` | GitHub Pages | бесплатно |
| Сервер и база | `worker/` | Cloudflare Workers + D1 | бесплатно |

Регистрируется на Cloudflare и GitHub **только главный админ**. Старостам нужны лишь ссылка на сайт и ключ группы.

## Как это работает

- **Главный админ** входит по своему паролю, создаёт группы и получает для каждой **ключ регистрации** (вида `K7M2-QX9P-4RTA`).
- **Староста** открывает сайт → «Регистрация по ключу» → вводит ключ и придумывает пароль. Ключ одноразовый: дальше вход только по паролю.
- Староста видит и меняет **только свою группу**: добавляет и удаляет учеников, ставит отметки, смотрит итог.
- Потерял пароль или ключ попал не к тому человеку → админ нажимает «Новый ключ»: старый пароль перестаёт работать, ученики и отметки остаются.
- Удалённый ученик пропадает из списка, но его прошлые отметки остаются в итогах тех недель.

### Правила отметок
- Учебные дни — понедельник–пятница. Суббота и воскресенье закрыты.
- Число пар в день задаёт староста (вкладка «Ученики», от 1 до 8).
- Староста может отмечать и исправлять дни **текущей недели** (не будущие) **до пятницы 15:10**. После этого неделя закрыта.
- Главный админ может исправить отметку за любой прошедший учебный день (кнопка «Открыть» у группы).
- Время везде ташкентское (UTC+5), и считает его сервер, поэтому неверные часы на телефоне ничего не ломают.

### Защита
- Все проверки делает сервер, а сайт только показывает данные. Ключей и паролей в коде сайта нет.
- Пароли хранятся как PBKDF2-хеш, ключи регистрации и токены входа — как SHA-256. Открытым текстом ничего не хранится.
- После 5 неверных паролей вход блокируется на 15 минут, после 10 неверных ключей — на 30 минут.
- Пароль старосты — от 8 символов. Вход запоминается на устройстве на 30 дней, кнопка «выйти» его сбрасывает.

## Выкладка (один раз, ~20 минут)

Нужны Node.js (уже есть) и терминал. Все команды выполняются в папке `worker/`.

### 1. Сервер на Cloudflare

1. Зарегистрируйтесь на <https://dash.cloudflare.com/sign-up> (бесплатно, карта не нужна).
2. Войдите из терминала (откроется браузер):
   ```bash
   cd worker
   npm install
   npx wrangler login
   ```
3. Создайте базу:
   ```bash
   npx wrangler d1 create attendance
   ```
   Команда выведет `database_id = "…"`. Вставьте это значение в `worker/wrangler.toml` вместо `ВСТАВЬТЕ-ID-ИЗ-КОМАНДЫ-d1-create`.
4. Создайте таблицы:
   ```bash
   npm run db:remote
   ```
5. Задайте пароль главного админа. Он хранится только у Cloudflare, в коде его нет:
   ```bash
   npx wrangler secret put ADMIN_PASSWORD
   ```
6. Запустите сервер:
   ```bash
   npm run deploy
   ```
   В конце появится адрес вида `https://attendance.ВАШ-НИК.workers.dev`.

### 2. Сайт на GitHub Pages

1. Впишите адрес сервера из шага 1.6 в `docs/config.js`.
2. Создайте на GitHub **публичный** репозиторий (Pages на бесплатном аккаунте работает только с публичными; секретов в коде нет) и загрузите папку `attendance`.
3. На GitHub: **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/docs` → Save**.
4. Через минуту сайт будет по адресу `https://ВАШ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
5. Разрешите серверу принимать запросы с этого сайта: в `worker/wrangler.toml` в `ALLOWED_ORIGINS` впишите `https://ВАШ-НИК.github.io` (без пути и без `/` в конце), затем снова `npm run deploy`.

### 3. Первые шаги
1. Откройте сайт → «Я главный админ» → пароль из шага 1.5.
2. Создайте группы и отправьте каждому старосте ссылку на сайт и ключ его группы.
3. На телефоне сайт можно добавить на главный экран: меню браузера → «Добавить на главный экран».

## Проверка у себя на компьютере

```bash
cd worker
npm run db:local                                   # таблицы в локальной базе (один раз)
npm run dev                                        # сервер на http://127.0.0.1:8787
python3 -m http.server 8788 --bind 127.0.0.1 -d ../docs   # сайт на http://127.0.0.1:8788 (в другом окне)
```
Для локальной проверки пароль админа и разрешённые адреса берутся из `worker/.dev.vars` (этот файл не попадает в git).
`docs/config.js` сейчас указывает на локальный сервер. Перед выкладкой замените адрес (шаг 2.1).

## Лимиты бесплатных тарифов
Cloudflare Workers — 100 000 запросов в день, D1 — 5 млн чтений и 100 000 записей в день. Одна отметка — 1 запрос.
Даже 50 групп по 30 человек и 4 пары в день используют меньше 5 % лимита.
